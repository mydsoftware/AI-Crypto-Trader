# PACT-OS

Personal AI Crypto Trading Assistant

## Features

- Connect to Tabdeal Exchange
- Market Scanner
- Technical Analysis
- AI Score Engine
- Trade Suggestions
- Mobile Dashboard (Future)

---

## Installation

Clone project

```bash
git clone https://github.com/USERNAME/PACT-OS.git
```

Create virtual environment

```bash
py -3.13 -m venv .venv
```

Activate

PowerShell

```powershell
.\.venv\Scripts\Activate.ps1
```

Install packages

```bash
pip install -r requirements.txt
```

Create .env

```text
TABDEAL_API_KEY=
TABDEAL_API_SECRET=
```

Run

```bash
python main.py
```
