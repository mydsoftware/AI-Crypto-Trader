# موتور تحلیل AI-Crypto-Trader

## منطق تحلیل

داده OHLCV در چند تایم‌فریم وارد موتور می‌شود. سپس اندیکاتورها و استراتژی‌های مستقل رأی می‌دهند و خروجی برای اجماع نهایی آماده می‌شود.

تایم‌فریم‌های هدف:
- 5m
- 15m
- 1h
- 4h
- 1d

### اصل ایمنی
این موتور فقط تحلیل و پیشنهاد تولید می‌کند و هیچ مسیر اجرای سفارش ندارد. نبود اجماع کافی باید به `WAIT` منجر شود.

### مرحله بعد
اتصال adapter صرافی به این لایه، ساخت pipeline واقعی OHLCV، سپس backtest و walk-forward validation قبل از فعال کردن رتبه‌بندی تولیدی.
